SIMPLIFIED GITHUB UPDATE

ONE-TIME INSTALL
Upload this index.html and assets folder into the repository root, replacing
matching files. Do not delete other files or clear browser site data.
Wait for GitHub Pages to deploy, then refresh your online website in the SAME
browser/profile where your edits are saved. Log in to Admin.

FOR EACH CONTENT UPDATE
1. Open Publishing and backups in Admin.
2. Click Download website update.
3. Upload the downloaded index.html to GitHub, replacing index.html, and commit.

Your text, uploaded photos, published posts, scores, colours and placements
are included in that one file. No separate site-content.js upload is needed.
Keep the existing assets folder. Check the shared link after deployment.
If your browser adds a suffix such as index (1).html, rename it to index.html
before uploading. The file must go in the repository root, not a subfolder.

The GitHub upload page is linked in Admin:
https://github.com/aucklandcurlwebsite-sudo/BusinessLeagueACC/upload/main

IMPORTANT
Downloading is not publishing: you must still upload and commit to GitHub.
The update button works on the online website, not a local file opened from disk.
Use Download backup periodically and before installing future template/code
upgrades. Re-export your saved content after installing a new blank template.
Never clear the browser data holding edits until you have a backup.

PRIVATE DRAFTS
The published index.html omits unpublished blog drafts, but includes the photo
library. Only upload library photos you intend to make public. Download backup
includes drafts; keep that JSON backup private and out of the public repository.

The existing browser-side Admin password is not server-side authentication.
This update does not store or require a GitHub token in the website.
